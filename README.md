# BlazeByte Studio — Modern Commercial SaaS Platform

Production-quality SaaS platform for **BlazeByte Studio**.
- Official website: [https://www.blazebyte.shop](https://www.blazebyte.shop)
- Primary Design Reference: [bharathraj0519-source/blaze-byte](https://github.com/bharathraj0519-source/blaze-byte)

---

## 🚀 Core Platform Architecture

### 1. Brand Identity & Design System
- **Main Background**: `#202734`
- **Primary Blue**: `#2391FF`
- **Secondary Text**: `#B7B09E`
- **Design Language**: Premium dark mode, frosted-glass cards, subtle blue ambient glow, thin translucent borders, responsive navigation with active hover line indicator.
- **Typography**: `Barlow` & sans-serif hierarchy for maximum contrast and high-density SaaS readability.

---

### 2. Platform Modules

#### Module 01 — AI Chatbot SaaS
- **Subscription Tiers**:
  - `Free`: Standard chat interface, basic FAQs, message allowance limits, standard support.
  - `Plus`: Smart business knowledge base, website embed snippet, automated lead capture, direct WhatsApp routing.
  - `Pro`: Multi-step automation logic, custom system instructions, CRM webhook integration simulation, unlimited vector documents.
- **Interactive Live Simulator**:
  - Instant live chat with typing indicators, suggested action chips, timestamps, clear history, and transcript export.
  - Tier simulation toggle (experience the difference between Free, Plus, and Pro intelligence levels).
  - Feature comparison matrix & transparent configurable pricing cards (Monthly / Annual with 20% discount).

#### Module 02 — Web Design & Development
- **Interactive Multi-Device Showcase**:
  - Toggle between **Desktop (1920px)**, **Tablet (768px)**, and **Mobile (375px)** device mockups with full-screen capability.
  - Live template switchers (`Corporate`, `SaaS Platform`, `E-Commerce`).
- **10 Service Capabilities**:
  1. Custom Website Development
  2. Modern Website Redesign
  3. Corporate Business Websites
  4. High-Converting Landing Pages
  5. E-Commerce Storefronts
  6. Responsive & Adaptive Design
  7. Performance & Core Web Vitals Optimization (99+ PageSpeed)
  8. Ongoing Website Maintenance
  9. Custom SaaS & Cloud Portals
  10. Third-Party API & Payment Gateway Integrations
- **Project Enquiry Engine**:
  - Validated intake form collecting client requirements, budget brackets, timeline, and feature sets with local persistence and direct WhatsApp hand-off.

#### Module 03 — SEO Services SaaS
- **Strict Compliance**: **No Free plan**. Available in **Plus** and **Pro** only.
- **Historical Demonstration Dataset** (Transparently identified as historical project data from `https://www.blazebyte.shop`):
  - 27 pages scanned in Google Search Console
  - 18 discovered pages
  - 4 high-priority indexing requests submitted
  - IndexNow key file verified & handshake active
  - 45 routes compiled in one deployment
  - `/marketing` content-gap issue marked cleared
  - Local Google Maps visibility issue cleared for selected target queries
  - Google Business Profile categories & details corrected
  - GBP photos & posts identified as continuous improvement area
  - Clutch business profile completed
- **Interactive Telemetry Console**:
  - Interactive impression & click charts via Recharts
  - Keyword tracking table with CPC and search volume
  - Technical hygiene issue tracker with severity badges
  - Downloadable/exportable SEO performance audit report

#### Module 04 — Custom Plan Builder
- **Dynamic Configurator**:
  - Multi-step interactive wizard across 4 categories:
    1. AI Chatbot
    2. Web Design & Development
    3. SEO Services
    4. Digital Marketing & Automation Add-ons
  - Real-time sticky summary panel with feature counts, category breakdown, timeline, and dynamic price estimates.
  - Generates unique reference ID (e.g. `ENQ-XXXX`) with instant WhatsApp quote discussion link.

### 3. Customer & Admin Management Console
- **Customer Workspace**:
  - Account overview, active subscription details, usage quotas, submitted project requests.
- **Admin Control Center**:
  - Passkey protected (`blazebyte2026`).
  - Real-time inquiry pipeline review (Filter by `New`, `In Review`, `Contacted`, `Archived`).
  - Export inquiries to JSON format.

## 🛠️ Technology Stack
- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`) + Glassmorphism Custom Utilities
- **Icons**: Lucide React
- **Data Visualization**: Recharts
- **State & Storage**: Centralized `storageService` with persistent browser client storage

---

## 💻 Running the Application

```bash
# Install dependencies
npm.cmd install

# Start local development server
npm.cmd run dev

# Build production assets
npm.cmd run build

# Preview production build
npm.cmd run preview -- --port 4173
```
